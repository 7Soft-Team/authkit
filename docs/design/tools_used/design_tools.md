# الأدوات المستخدمة في مرحلة التصميم

| الأداة | الاستخدام |
|---|---|
| DrawDB | تصميم مخطط ERD وقاعدة البيانات وتحديد الجداول والحقول والمفاتيح والعلاقات. |
| Microsoft Word | تنسيق النصوص والجداول وصياغة المتطلبات والمحتوى التحريري قبل نقلها إلى Markdown. |
| Markdown | كتابة وتنظيم وثائق المشروع وعرض الجداول والمخططات داخل المستودع. |
| GitHub | عرض الوثائق والمخططات وتخزين المشروع وإدارة النسخ والتغييرات. |
| Microsoft Visio | إنشاء المخططات الهندسية ومخططات تدفق البيانات والمخططات الانسيابية. |
| Microsoft PowerPoint | إعداد شرائح عرض المشروع وتنظيم المحتوى والمخططات بصرياً. |
| Draw.io | تصميم المخططات الانسيابية ومخططات التدفق وDFD بالصور والأشكال الهندسية. |
| Gemini | المساعدة في تنظيم الأفكار وصياغة الشرح ومراجعة وضوح المخططات والنصوص. |
| ChatGPT | المساعدة في صياغة التوثيق العربي وتنظيم الجداول والشرح التقني. |
| GitHub Copilot | المساعدة في كتابة مستندات Markdown وتنظيم الروابط والمراجعة البرمجية والتوثيقية. |
