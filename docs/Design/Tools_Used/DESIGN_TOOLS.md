# الأدوات المستخدمة في مرحلة التصميم

توثق هذه الصفحة الأدوات البرمجية وأدوات الذكاء الاصطناعي المستخدمة لإنشاء مخططات مرحلة التصميم وترتيب الوثائق وتنسيقها.

## أدوات إنشاء مخططات قاعدة البيانات

### DrawDB

استُخدم **DrawDB** لإنشاء مخطط ERD وتصميم قاعدة البيانات بصرياً، مع تحديد الجداول والحقول والمفاتيح الأساسية والأجنبية والعلاقات بين كيانات النظام.

## أدوات توثيق المحتوى وإعداد الوثائق

### Microsoft Word

استُخدم **Microsoft Word** لتنظيم النصوص والجداول وصياغة المتطلبات والمحتوى التحريري أثناء إعداد وثائق المشروع قبل نقلها إلى ملفات Markdown.

### Markdown وGitHub

استُخدمت ملفات Markdown لتنظيم الوثائق ضمن مستودع المشروع، بينما يمكن لـGitHub عرض النصوص والجداول والمخططات بصورة مباشرة وواضحة عند رفع المشروع.

## أدوات إنشاء المخططات الانسيابية وDFD

### Microsoft Visio

استُخدم Microsoft Visio لإنشاء المخططات الهندسية والرسومية المنظمة، ومنها مخططات تدفق البيانات ومخططات التدفق الانسيابي.

### أدوات مخططات التدفق

يمكن استخدام Microsoft Visio أو Microsoft PowerPoint أو Draw.io لإنشاء المخططات الانسيابية، وتدعم هذه الأدوات أشكال البداية والنهاية والقرار والإدخال والإخراج والتنفيذ.

## أدوات العرض التقديمي

### Microsoft PowerPoint

استُخدم Microsoft PowerPoint لإعداد وعرض شرائح المشروع وتنظيم عرض فكرة النظام ومراحل التحليل والتصميم والمخططات بصورة مرئية.

## أدوات الذكاء الاصطناعي المساندة

### Gemini

يُستخدم Gemini للمساعدة في تنظيم الأفكار وصياغة الشرح وتقترح مراجعة المخططات والنصوص للتأكد من وضوحها واتساقها.

### ChatGPT

يُستخدم ChatGPT للمساعدة في إعادة صياغة التوثيق العربي وتنظيم الجداول والشرح التقني واقتراح تحسينات على بنية الملفات والمحتوى.

### GitHub Copilot

يُستخدم GitHub Copilot للمساعدة في كتابة وتنسيق مستندات Markdown، وإضافة الروابط، ومراجعة اتساق الوثائق والتعديلات البرمجية المرتبطة بالمشروع.

## ملخص استخدام الأدوات

| نوع العمل | الأداة المستخدمة |
|---|---|
| تصميم مخطط ERD وقاعدة البيانات | DrawDB |
| إعداد الوثائق والنصوص والجداول | Microsoft Word وMarkdown |
| إنشاء مخططات DFD ومخططات التدفق | Microsoft Visio أو Draw.io |
| إعداد العرض التقديمي للمشروع | Microsoft PowerPoint |
| المساعدة في الصياغة والمراجعة والتنظيم | Gemini وChatGPT وGitHub Copilot |
| عرض الوثائق والمخططات على المشروع | GitHub |
