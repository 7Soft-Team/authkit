# مرحلة التصميم

تمثل مرحلة التصميم المرحلة التي تُحوّل متطلبات ومخرجات مرحلة التحليل إلى تصور تقني منظّم يوضح كيفية بناء النظام وتنظيم بياناته وتعاقب العمليات داخله.

تحدد هذه المرحلة بنية النظام والكيانات وتدفق المعلومات والمسارات البرمجية، كما توضح العلاقات بين أجزاء النظام وتوزيع المسؤوليات قبل البدء في التنفيذ البرمجي.

تشمل وثائق مرحلة التصميم في هذا المشروع العناصر التالية:

- **DFD:** مخططات تدفق البيانات التي توضح كيفية انتقال البيانات بين الأطراف والعمليات ومخازن البيانات.
- **ERD:** مخطط العلاقات بين الكيانات الذي يوضح هيكل قاعدة البيانات والعلاقات والقيود الأساسية.
- **Data Dictionary:** قاموس البيانات الذي يوثق الجداول والحقول وأنواعها وقيمها وقواعدها.
- **Algorithms:** وصف الخطوات المنطقية والخوارزميات المستخدمة لتنفيذ عمليات النظام.
- **Flow Charts:** مخططات انسيابية توضح تسلسل العمليات واتخاذ القرار داخل وظائف النظام.
- **Tools Used:** الأدوات البرمجية وأدوات الذكاء الاصطناعي المستخدمة في إعداد وثائق ومخططات مرحلة التصميم.
